Crate dtk 

Source
Expand description

dtk: finds tables in command output and renders short, typed summaries of them.

The dtk binary uses this library for its Claude Code hook. Other programs, such as an rtk plugin, can call it directly:

let ctx = dtk::lean::Ctx { bytes: 0, csv_path: None, raw_path: None };
assert!(dtk::summarize("not a table", &ctx, 2500).is_none());

Modules§

ghcli
Output of the GitHub CLI (gh) when it is not on a terminal.
lean
Lean views: a small, typed summary of a table that keeps what an agent acts on.
outline
An outline of a JSON document that is not a table: cargo metadata, terraform show -json, an API response with a few big records, a lock file.
table
Table detection: turns raw command output into a header plus rows, or says “not a table”.

Functions§

summarize
Finds a table in text and renders its lean view. None means text is not a table.
